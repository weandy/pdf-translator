# doc-translator

自用的网页端 PDF 保版式翻译工具：上传 PDF，在浏览器里按原版式对照阅读中文译文，公式、图表按原位置重新渲染，可导出纯译文或双语 PDF。

> 当前阶段：调研与技术选型，尚未开始编码。

## 目标

- **保留原版式**：译文排回原位置，图片、矢量图形、独立公式保持不动
- **公式图表重新渲染**：行内公式用 KaTeX 随译文重排，表格、图内文字可翻译
- **可接外部 API**：翻译走任意 OpenAI 兼容接口（DeepSeek、通义千问、GLM、Ollama 等），解析可选 MinerU 云端 API、Doc2X
- **论文术语一致**：领域术语库 + 文档级术语自动抽取
- **无 GPU 可用**：本地只用 CPU，重型解析交给可选的云端 API
- **翻译方向**：其他语言 → 简体中文（以英文为主）
