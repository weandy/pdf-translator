## 1. 手机适配

**目标**：390 px 宽的手机上能正常阅读、点段落修改。

| 部分 | 设计 |
|---|---|
| 顶栏 | 窄屏（≤ 640 px）站名缩短为“保版式翻译”；导航项不换行（`white-space: nowrap`）；“源代码”链接在窄屏隐藏（页脚已有仓库链接时不重复） |
| 阅读器默认模式 | 首次打开时，视口宽度 < 760 px 默认“译文”单页并适应宽度；用户切换后以用户选择为准（本次打开有效） |
| 工具栏 | 窄屏紧凑排列：标题一行省略，统计信息小字；显示方式与缩放一行，“修改记录”“下载”一行；整体高度不超过约 100 px |
| 段落编辑、修改记录面板 | 窄屏改为**底部弹出**（`position: fixed`，最高 70% 屏高，可滚动，上方留出可点的阅读区）；关闭按钮常驻 |

**验收**：390×844 视口下页面无横向滚动；阅读器正文字号 ≥ 10 px；点段落后编辑面板立即可见。

## 2. 解析阶段自动重试、错误说明

**依据**：3 个失败任务全是网络问题，用户只能手动点重试；“内部错误，请查看服务日志”对用户没有意义。

**设计**
- `ParseError` 增加 `retryable`（网络超时、连接失败、上传停滞、云端 5xx 为真；Token 无效、文件被拒、额度用完为假）。
- 流水线解析阶段遇到可重试错误，自动重试 2 次，间隔 15 秒、45 秒；等待时显示“网络不稳定，15 秒后自动重试（第 1/2 次）”。重试仍失败才标记失败。
- 意外异常的提示改为“处理时出现意外错误（{阶段名}）。可以点“重试”从中断处继续；多次失败请反馈”，日志里照常记录完整堆栈。

**验收**：模拟解析器前两次抛可重试错误、第三次成功 → 任务完成，期间出现自动重试提示；不可重试错误不重试。

## 3. 只翻部分页

**依据**：后端已支持 `options.pages`（0 起页码），界面没有开放。长报告、学位论文、书籍章节常只需要其中几页。

**设计**
- 只选一个文件时，上传面板显示“页码范围（可选）”输入框，格式如 `1-10, 15, 20-22`（1 起，前端换成 0 起）；留空表示全部。
- 实时校验：格式错误、超出总页数时提示并禁用开始按钮；费用与用时预估按所选页数计算。
- 版面解析仍解析全文（MinerU 的页码与原文对应最稳），页数上限仍按全文计；只翻译所选页，其他页在阅读器与导出中保持原文。

**验收**：选 `2-3` 的任务只有第 2、3 页有译文段落；预估按 2 页计算。

## 4. 翻译收尾提速

**依据**：最后一轮“逐段开思考重翻”没有时限，个别难段落拖住整篇任务两分钟以上。

**设计**
- 进入最后一轮时显示“还有 N 段较难，正在开思考重翻”（进度回调带说明文字）。
- 最后一轮每段限时 90 秒（`asyncio.wait_for`），超时按失败处理：段落标灰，任务照常完成，用户可在阅读器里点灰色段落重翻。
- 限时可配置（`TranslateOptions.final_round_timeout_s`），测试里设得很短。

**验收**：模拟模型在最后一轮卡住 → 任务按时完成，该段为失败状态。

## 5. 完成提醒

**设计**
- 进度页与阅读页：任务进行中浏览器标签标题显示“47% · 文件名”，完成后“✓ 已完成 · 文件名”，失败“✗ 失败 · 文件名”。
- 首页有任务在进行时标题显示“(1/3 完成) PDF 保版式翻译”。
- 进度页提供“完成时通知我”按钮：点击时申请浏览器通知权限，任务完成或失败时弹出桌面通知（权限被拒时按钮显示原因）。

## 6. 取消任务

**目标**：排队中或进行中的任务可以取消；取消后保留在“我的任务”里，显示“已取消”，可以重新开始（从中断处继续）或删除。

**状态**：`JobStatus` 增加 `cancelled`。

```
queued ──取消──► cancelled ──重试──► queued
running ─取消──► cancelled
cancelled ──删除──► （删除）
```

**后端**
- `POST /api/jobs/{id}/cancel`：只对排队中、进行中的任务有效，否则 400。
- `Pipeline.cancel(job_id)`：先把任务记入“用户取消”集合，再取消它的 asyncio 任务。`_run` 捕获 `CancelledError`：在集合里的标记为 `cancelled`（消息“已取消”），否则（服务停止）照原逻辑往上抛。
- 排队等名额时取消：`Slots.hold` 的 `finally` 已会把它移出队伍并更新其他任务的排位。
- 已完成的阶段与译文缓存都保留，重试时从中断的阶段继续，已翻过的段落命中缓存不再计费。
- 重试接口允许 `cancelled`；删除接口允许 `cancelled`；统计“进行中的任务”时不计 `cancelled`。

**前端**
- 进度页：“取消翻译”按钮（确认后取消），取消后显示“已取消”及“重新开始”“删除”。
- 首页“我的任务”：排队中、进行中的任务有“取消”按钮；已取消的显示“已取消”，可删除。

**验收**：取消排队中与进行中的任务均变为已取消；重试后完成；其他排队任务的排位随之更新；服务停止时进行中的任务不会被误标为“已取消”。
