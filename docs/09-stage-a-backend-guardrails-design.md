# 阶段 A 后端确定性护栏与单机内存预算

## 上传与 MinerU

原上传路由将 multipart 文件重新读成一份完整的 Python 字节串，并在事件循环上读 PDF 页数、写文件和提交数据库事务。接收用例先检查工件根目录所在磁盘的剩余空间，再读取并校验前 4 字节的 `%PDF`。通过校验后将 multipart 文件分块复制到工件根目录内的临时文件，达到字节上限即停止复制。关闭临时文件句柄后在同一文件系统上原子发布 `original.pdf`。页数、磁盘和事务检查在线程执行，排队额度涵盖正在接收的任务，调度回到事件循环。已提交接收事务的任务仍应完成调度，未提交的上传和失败工件应清理。保留直接传入 `bytes` 的接收入口。

MinerU 的每次 PUT 从文件头开始读取小块，使用文件长度作为 `Content-Length`。上传总时限和传输无进展分别提示。退出上传等待时取消内部 HTTP 任务，重复取消也要等请求收尾后才关闭上传文件。云端结果以分块方式写入临时 ZIP，下载上限为 512 MiB，有效的长度声明和实际传输字节都受限。在线程中读取并归一化目标条目 `layout.json`，其解压上限为 64 MiB。契约测试依赖 `parser/mineru.zip`，因此保留通过校验的原始 ZIP，并纳入任务既有保留期。取消时等待解压线程退出，再清理临时 ZIP。

## 融合页号

按位置组合两个页面列表会把缺页之后的块分给错误页面，还会截掉末页。融合按零起 PDF 页号检查解析结果，拒绝负值、重复和越界，对外给出可定位的阶段错误。乱序时按真实页号输出。缺失的解析页保留原 PDF 页号、尺寸、类型及空块，在融合报告中记录，后续翻译与背景处理仅使用已有块。跨页续行只搜索页号相差一的下一页，防止越过缺页。

## 导出与重任务

导出原先先构造完整的 Python PDF 字节串，再把副本写盘。生产入口使用 PyMuPDF `save` 写临时文件，关闭后原子发布，保留原来的字节返回入口。磁盘缓存保留原有摘要、文件名及 Range 语义。先检查缓存，缓存未命中才使用流水线同一个容量为一的本机槽。相同任务、格式、侧别和译文快照共享一次生成，编辑后的请求独立生成。导出排队和生成期间保护工件，服务停机等待在途导出。准备接口在工件保护内读取文件大小，下载期间继续保护文件。旧导出超过 60 秒且同一任务没有并行工件读取时才清理。背景页以独立临时名发布。删除、过期清理及孤儿目录入队都通过同一工件保护。

## SQLite 与断点

任务仓储、译文缓存与管理员会话连接统一使用 15 秒 SQLite 等待。写入显式开启事务，写语句或提交阶段遇到锁冲突时先回滚再重试，锁错误快速返回时最多做两次短退避。任务、统计和提交账本仍在同一事务。阶段 JSON 先写同目录 `.part`，成功后发布，失败清理临时文件。断点检测继续使用正式文件路径。

## 模型连接池

工厂每次创建的客户端由调用它的阶段或用例关闭。术语抽取复用同一客户端调用模型和取得计费模型名。真实适配器关闭 SDK 连接池，测试替身可省略关闭方法。关闭发生在成功、错误或取消以后。

## 回归验证

- 上传覆盖限额、临时文件清理、接收并发、事件循环响应和取消后的接收一致性。
- MinerU 覆盖流式 PUT 长度、失败重传、取消期间回收请求、流式 ZIP、非法归档和解压上限。
- 融合覆盖乱序、缺页、负值、重复、越界及真实邻页续行，并验证缺页文档能完成切分、背景生成和双语导出。
- 导出覆盖磁盘缓存绕过名额、同快照合并、编辑后的并行请求、失败后重新生成、过期清理延后、线程取消、原子发布和 Range。
- 存储与模型覆盖锁冲突、事务回滚、JSON 写失败、模型工厂调用次数与资源释放。
- 顺序执行 Ruff 格式、Ruff 检查、Pyright、import-linter 及全部 pytest，其中含 OpenAPI 同步检查。
