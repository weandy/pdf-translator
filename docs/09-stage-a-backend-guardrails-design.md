# 阶段 A 后端确定性护栏与单机内存预算

## 上传与 MinerU

原上传路由将 multipart 文件重新读成一份完整的 Python 字节串，并在事件循环上读 PDF 页数、写文件和提交数据库事务。接收用例将 multipart 文件分块复制到数据目录内的临时文件，达到字节上限即停止复制。临时文件与任务目录位于同一文件系统，关闭句柄后用原子替换发布 `original.pdf`。页数、磁盘和事务检查在线程执行，排队额度涵盖正在接收的任务，调度回到事件循环。已提交接收事务的任务仍应完成调度，未提交的上传和失败工件应清理。保留直接传入 `bytes` 的接收入口。

MinerU 的每次 PUT 从文件头开始读取小块，使用文件长度作为 `Content-Length`。退出上传等待时取消并回收内部 HTTP 任务。云端结果以分块方式写入临时 ZIP，将 ZIP 下载上限设为 512 MiB，解压后的 `layout.json` 上限设为 64 MiB。只读取目标条目。契约测试依赖 `parser/mineru.zip`，因此保留通过校验的原始 ZIP，并纳入任务既有保留期。临时 ZIP 在异常和取消后清理。

## 融合页号

按位置组合两个页面列表会把缺页之后的块分给错误页面，还会截掉末页。融合按零起 PDF 页号检查解析结果，拒绝负值、重复和越界，对外给出可定位的阶段错误。乱序时按真实页号输出。缺失的解析页保留原 PDF 页号、尺寸、类型及空块，在融合报告中记录，后续翻译与背景处理仅使用已有块。跨页续行只搜索页号相差一的下一页，防止越过缺页。

## 导出与重任务

导出原先先构造完整的 Python PDF 字节串，再把副本写盘。生产入口使用 PyMuPDF `save` 写临时文件，关闭后原子发布，保留原来的字节返回入口。磁盘缓存保留原有摘要、文件名及 Range 语义。先检查缓存，缓存未命中才使用流水线同一个容量为一的本机槽。相同任务、格式、侧别和译文快照共享一次生成，编辑后的请求独立生成。取消等待时等线程实际退出，再释放槽位及工件保护。背景页以独立临时名发布。删除与保留期清理在后台写工件时延后。

## SQLite 与断点

任务表和译文缓存连接使用 15 秒 SQLite 等待。写入使用完整事务，明确回滚后才重试锁冲突，锁错误快速返回时最多做两次短退避。任务、统计和提交账本仍在同一事务。阶段 JSON 先写同目录 `.part`，成功后发布，失败清理临时文件。断点检测继续使用正式文件路径。

## 模型连接池

工厂每次创建的客户端由调用它的阶段或用例关闭。术语抽取复用同一客户端调用模型和取得计费模型名。真实适配器关闭 SDK 连接池，测试替身可省略关闭方法。关闭发生在成功、错误或取消以后。

## 回归验证

- 上传覆盖限额、临时文件清理、接收并发、事件循环响应和取消后的接收一致性。
- MinerU 覆盖流式 PUT 长度、失败重传、取消期间回收请求、流式 ZIP、非法归档和解压上限。
- 融合覆盖乱序、缺页、负值、重复、越界及真实邻页续行。
- 导出覆盖磁盘缓存绕过名额、同快照合并、与流水线共享名额、线程取消、原子发布和 Range。
- 存储与模型覆盖锁冲突、事务回滚、JSON 写失败、模型工厂调用次数与资源释放。
- 顺序执行 Ruff 格式、Ruff 检查、Pyright、import-linter 及全部 pytest，其中含 OpenAPI 同步检查。
