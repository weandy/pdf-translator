# Q1 翻译质量护栏

本轮保持原有提示词版本、批量请求与重试预算。使用合成 PDF 和离线模型响应验证。

| 问题 | 设计与不变量 | 回归 |
| --- | --- | --- |
| 斜体跨行 | 整块斜体和标题沿用块级样式。行、词及跨块拼接保留连续的局部强调，合并时维持标签嵌套。 | 多行整块斜体、局部强调、粗斜体混排及断词。 |
| 模型结束状态和编号 | 适配器保留服务商结束状态。批次被拒绝或命中内容过滤时拆成单段重试，单段遇到同类结束状态时立即记失败。截断时仅验收最后一个编号之前的完整段。重复、越界或乱序编号使整批进入单段重试。 | 两种拒绝状态下同批其他段可成功，命中拒绝的段共尝试两次。两种协议的离线响应、带文字拒绝、末段截断、重复及越界编号、英文续行。 |
| 富文本与上下标 | 模型输出和缓存使用同一验收函数，比较四种标签的数量和结构。人工编辑共用栈校验，允许调整数量和范围。伪上下标规则在 PDF 和阅读器一致，保护无空白的技术标识。 | 缺标签、交叉和空标签、人工保存，以及双端相同的真假上下标样例。 |
| 照抄和长度异常 | 先去掉公式占位、格式、引文、网址和有明确路径特征的文本。以汉字与英文词数的比例识别原文，检查极少汉字且英文相似度高的照抄，也检查简短引导语后完整保留英文的情况。较长英文正文的译文长度上限为原文英文字母数的 2.2 倍，另检查整段译文连续重复四次以上。 | 拦截中文前缀照抄、带汉字例字的英文照抄、整段复读及含普通斜杠词的照抄。保护短标题、名称、指标、公式短段、中文原文和紧凑意译。 |
| 扫描页与未定位行内公式 | 可定位的公式沿用原图裁片。无裁片时将 LaTeX 连同数学界定符排入译文，公式文本保留在 PDF 中，链接匹配跳过公式。无字符时去除 LaTeX 两端空白，按实际生成的非空公式片段计数。 | 合成扫描页的 PDF 提取文本含公式，验证裁片路径及引用链接落在公式之后的引用编号。 |
| 跨页链接 | 译文侧使用重定位后块的页号和该页宽度。原文侧的页号和内部跳转目标沿用原 PDF。 | 不同宽度的双栏跨页文件，覆盖单语和双语左右两种模式。 |
| 指定页 | 仅在选页内且可参与切段的块之间建立续接关系。前驱位于未选页、首页作者区或不可翻译块时，有效续块独立成段。段落部件同时限定去字范围。 | 同一续接链分别选起始页、尾页及不连续页，验证作者区及不可翻译块之后的续块。 |
| 漏页和溢出 | 选页内有内容的原生页和扫描页缺少解析时写入 IR，任务完成摘要和阅读器显示页号。乱码页沿用自身状态。导出按排版行高和 0.5 pt 容差判定框内适配，按实际绘制底边复核邻块和页底。常规最小字号仍溢出时向下借用同栏空白，超过可用空间时记录溢出并截取完整行。极矮框允许首行低于常规最小字号。导出缓存版本升至 5，输出页数与原文一一对应。 | 有字、图像、空白、未选及乱码漏页。验证单行标题、正文和图注的字号，以及扩框、相邻块、页底和极矮框首行。 |
