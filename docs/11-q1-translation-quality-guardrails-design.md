# Q1 翻译质量护栏

本轮保持原有提示词版本、批量请求与重试预算。使用合成 PDF 和离线模型响应验证。

| 问题 | 设计与不变量 | 回归 |
| --- | --- | --- |
| 斜体跨行 | 整块斜体和标题沿用块级样式。行、词及跨块拼接保留连续的局部强调，合并时维持标签嵌套。 | 多行整块斜体、局部强调、粗斜体混排及断词。 |
| 模型结束状态和编号 | 适配器保留服务商结束状态。拒绝的批次直接记失败。截断时仅验收最后一个编号之前的完整段。重复、越界或乱序编号使整批进入单段重试。 | 两种协议的离线响应、带文字拒绝、末段截断、重复及越界编号、英文续行。 |
| 富文本与上下标 | 模型输出和缓存使用同一验收函数，比较四种标签的数量和结构。人工编辑共用栈校验，允许调整数量和范围。伪上下标规则在 PDF 和阅读器一致，保护无空白的技术标识。 | 缺标签、交叉和空标签、人工保存，以及双端相同的真假上下标样例。 |
| 照抄和长度异常 | 先去掉公式占位、格式、引文、网址和路径，再识别英文正文。照抄需同时符合极低汉字量和高文本相似度。长度异常仅检查较长英文正文。 | 拦截照抄、严重缩水和暴涨。保护短标题、名称、指标、公式短段和紧凑中文译文。 |
| 扫描页行内公式 | 可定位的公式沿用原图裁片。无裁片时将 LaTeX 连同数学界定符排入译文，保留相邻文字。 | 合成扫描页的 PDF 提取文本含公式，验证裁片路径。 |
| 跨页链接 | 译文侧使用重定位后块的页号和该页宽度。原文侧的页号和内部跳转目标沿用原 PDF。 | 不同宽度的双栏跨页文件，覆盖单语和双语左右两种模式。 |
| 指定页 | 仅在选中的块之间建立跨页续接关系。续块可独立成为链头，段落部件同时限定去字范围。 | 同一续接链分别选起始页、尾页及不连续页，检查背景与段落范围。 |
| 漏页和溢出 | 选页内有内容的漏页写入 IR，任务完成摘要和阅读器显示页号。导出在最小字号仍溢出时向下借用当前列的空白，避开其他块及页底。仍超高时记录页号、块和超出点数，限定绘制范围。导出缓存版本升至 4，输出页数与原文一一对应。 | 有字、图像、空白和未选漏页。合成双栏页验证扩框、相邻块、页底及溢出日志。 |
